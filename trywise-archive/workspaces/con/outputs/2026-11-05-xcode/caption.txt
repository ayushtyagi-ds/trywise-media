Building Apple apps? GitHub announced Copilot in Xcode’s built-in coding assistant on November 4. This public preview starts with Xcode 27.3 beta and requires macOS Tahoe 26.6 or later. All Copilot plans are supported, according to GitHub. The existing extension remains a separate option.
